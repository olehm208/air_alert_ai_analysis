### AI-Assisted Development

This project was developed using ChatGPT as the primary engineering assistant.

AI was used for:
- Designing the application architecture and preprocessing pipeline.
- Implementing Python modules, automated tests, and the Streamlit interface.
- Developing and evaluating forecasting models.
- Identifying potential data leakage and methodological limitations.
- Debugging and improving the application based on local testing.

The developer was responsible for selecting the project direction, configuring the data sources, running and validating the generated code, making design decisions, and reviewing the final results.
